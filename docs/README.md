# Dokumen sumber Top Hills

SOP utama untuk implementasi terkini: [SOP v0.4 terbaru](sop/SOP-Top-Hills-v0.4-latest.docx). Lihat [audit implementasi](../SOP-V04-RELEASE-AUDIT.md) untuk bagian yang tersedia/sebagian/belum aktif.

- `sop/`: versi 0.2, 0.3 dan 0.4 terbaru.
- `sop/archive/`: unggahan v0.4 sebelum unggahan terakhir, disimpan untuk penelusuran. Bila isinya identik, hash pada manifest akan sama.
- `requirements/`: requirement Menu Laporan (P&L, neraca, arus kas).
- `design/`: arahan visual asli.
- `source-documents.json`: pemetaan nama unggahan, nama file repository dan hash SHA-256.
- `supabase/MIGRATION-HANDOFF.md`: kondisi database dan pekerjaan migrasi berikutnya.

File unggahan disalin utuh; isi dokumen sumber tidak diedit. Nama dinormalisasi hanya agar tautan dan path mudah digunakan. Dokumen design adalah referensi, bukan instruksi otomatis untuk deployment atau perubahan izin.
